# Excel Data Automation Pipeline

Excel Data Automation Pipeline is a **Python-based data processing and spreadsheet automation pipeline** that demonstrates headless Excel workbook engineering alongside live Microsoft Excel application interaction.

The project uses OpenPyXL to construct native formulas, apply formatting, and build calculated columns without requiring an active Excel GUI, followed by xlwings to manipulate live Excel workbooks, perform Pandas aggregations, and automatically generate an executive summary tab.

## Project Features

- Headless generation and modification of Excel workbooks using OpenPyXL
- Native Excel formula injection (SUM, IF, multiplication)
- Professional cell formatting, custom borders, alignment, and currency styling (`₹#,##0.00`)
- Dynamic auto-fitting of column widths based on content length
- Live Excel application interaction via xlwings
- Pandas integration for regional data aggregation and metrics calculation
- Dynamic creation and formatting of an Executive Summary worksheet
- Highlighting key metrics and conditional data presentation directly in Excel

## File Information

| File / Folder                 | Purpose                                                                                                            |
| ----------------------------- | ------------------------------------------------------------------------------------------------------------------ |
| `01_generate_sample_data.py`  | Script to generate the initial unformatted raw dataset (`Raw_Sales_Data.xlsx`)                                     |
| `02_openpyxl_automation.py`   | Headless pipeline that injects calculated columns, formulas, borders, and number formatting using OpenPyXL         |
| `03_xlwings_automation.py`    | Live automation script that aggregates regional sales with Pandas and builds an `Executive_Summary` sheet in Excel |
| `Raw_Sales_Data.xlsx`         | Sample input workbook containing transactional sales data                                                          |
| `Cleaned_Sales_OpenPyXL.xlsx` | Formatted output workbook generated by OpenPyXL containing calculated totals and styled summary rows               |
| `requirements.txt`            | Defines necessary Python library dependencies (`pandas`, `openpyxl`, `xlwings`)                                    |

## Installation

### 1. Open the Project Folder

```text
cd excel-automation-pipeline
```

### 2. Create a Virtual Environment

```text
python -m venv venv
```

### 3. Activate the Virtual Environment

For Command Prompt:

```text
venv\Scripts\activate
```

For PowerShell:

```text
venv\Scripts\Activate.ps1
```

For macOS/Linux:

```text
source venv/bin/activate
```

### 4. Install the Required Libraries

```text
pip install -r requirements.txt
```

## How to Run

### 1. Generate Raw Input Data

Run the data creation script to generate the sample sales dataset:

```text
python 01_generate_sample_data.py
```

This command creates:

```text
Raw_Sales_Data.xlsx
```

### 2. Execute Headless OpenPyXL Processing

Parse the raw file, inject native formulas, apply cell formatting, and generate the cleaned workbook:

```text
python 02_openpyxl_automation.py
```

This command creates:

```text
Cleaned_Sales_OpenPyXL.xlsx
```

### 3. Execute xlwings Live Excel Automation

Launch Excel automation to aggregate regional data via Pandas and generate the Executive Summary sheet:

```text
python 03_xlwings_automation.py
```

## System Workflow

```text
Generate Raw Sales Data (Pandas)
           ↓
Raw Sales Data (Raw_Sales_Data.xlsx)
           ↓
Headless OpenPyXL Script Processing
           ↓
Cleaned Sales Data (Cleaned_Sales_OpenPyXL.xlsx)
           ↓
Live xlwings Excel Application Interaction
           ↓
Updated Workbook with Executive Summary
```

## Tool Comparison: OpenPyXL vs. xlwings

| Capability           | OpenPyXL                                        | xlwings                                                |
| -------------------- | ----------------------------------------------- | ------------------------------------------------------ |
| **Excel Dependency** | No (Runs headless on servers/CI-CD pipelines)   | Yes (Requires MS Excel installed)                      |
| **Primary Focus**    | Reading/Writing `.xlsx` XML structures directly | Automating live Excel desktop application              |
| **Performance**      | High efficiency for bulk data & XML styling     | Ideal for live interactive reporting & VBA integration |
| **Formulas**         | Writes formula text strings into cells          | Evaluates live calculated formula values               |

## Important Note

The live automation script (`03_xlwings_automation.py`) requires Microsoft Excel to be installed on the host system. For headless environments or server deployments without Excel installed, execute the OpenPyXL pipeline (`02_openpyxl_automation.py`).
